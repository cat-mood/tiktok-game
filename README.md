# Брейнрот клипы

Локальная игра для IT-мастер-класса. Дети подключаются с телефонов по Wi-Fi, ведущий управляет лобби с ноутбука.

## Запуск

Нужен Node.js 20+.

```bash
cp .env.example .env
# Windows: copy .env.example .env
npm install
npm run dev
```

В `.env` задай секретный код админа:

```
ADMIN_CODE=changeme
PORT=3000
```

Узнать IP:

```bash
# macOS
ipconfig getifaddr en0

# Windows (смотри IPv4 у Wi-Fi / Ethernet, обычно 192.168.x.x)
ipconfig
```

- Игроки: `http://<IP>:3000`
- Админ: `http://<IP>:3000/admin`

На телефоне нужен именно `http://`, не https. После смены конфига перезапусти `npm run dev`.

Если страница не открывается: выключи VPN на ноутбуке, проверь что телефон в той же сети (не гостевой Wi-Fi). На Windows разреши Node.js в брандмауэре, когда система спросит, или: Параметры → Брандмауэр → Разрешить работу приложения.

Для мастер-класса без Vite:

```bash
npm start
```

Сервер слушает `0.0.0.0`, состояние пишется в `data/current.json`.

## Если что-то упало

- Телефон игрока: пусть откроет ту же ссылку — вернётся в свой отдел.
- Вкладка админа: снова `/admin` и код. Игра не сбрасывается.
- Сервер/ноут: `npm run dev` или `npm start`. Последняя сессия поднимается с диска. Игроки переподключаются сами. Админ видит баннер «Восстановлена игра».

## Новый поток детей

В админке нажми **Новая игра**. Текущая сессия копируется в `data/archive/`, лобби обнуляется.

## Скрипты

```bash
npm run dev    # сервер :3001 + клиент :3000
npm start      # собранный клиент с сервера :3000
npm test       # правила лобби и снапшоты
```
